# Mubu Exporter

[简体中文](README.md) · [English](README.en.md) · [Español](README.es.md) · **日本語**

幕布（Mubu）のアウトラインを、移行しやすい Markdown に変換します。フォルダー、書式付きテキスト、タスクの状態、表、数式、文書間の参照を保持し、画像をローカルに保存することもできます。

Python 3.10+ · Windows / Linux · [MIT](LICENSE)

## サンプルを試す

リポジトリに収録した手作りのサンプルは、幕布のアカウントやトークンを使わず、オフラインで変換できます。リポジトリのルートから実行してください。

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install .
mubu-export inspect --cache examples/cache
mubu-export export --cache examples/cache --out exports/demo --images skip
```

Linux / macOS では `source .venv/bin/activate` で環境を有効にします。`exports/demo/index.md` を開くと、出力された文書の一覧を確認できます。出力ディレクトリは新規である必要があり、再実行時は別の名前を指定します。

入力は[サンプルキャッシュ](examples/cache)、実際の変換結果は[エクスポートのプレビュー](examples/preview/index.md)で参照できます。いずれも架空の内容です。

## 保持できる内容

| 内容 | Markdown での表現 |
| --- | --- |
| フォルダーと同名の文書 | ID に基づく一意で安定したパス。Windows の予約名と大文字・小文字による衝突を回避 |
| アウトライン | 階層に応じた見出し、または完全な入れ子リスト |
| 太字、斜体、取り消し線、インラインコード | Markdown 記法。コード内のバッククォートと空白を保持 |
| ハイライト、穴埋め | `==ハイライト==`、`{{穴埋め}}`。表示はリーダーに依存 |
| 下線と色 | 一部 HTML を使用。`--no-color` で色を省略可能 |
| 数式 | `$LaTeX$`。リーダーの数式対応が必要 |
| タスクと注記 | `- [ ]` / `- [x]`、引用ブロック |
| 通常の表 | GFM の表。セル内でエスケープされた文字と改行を保持 |
| 文書参照 | エクスポート済み文書は相対リンクとノードのアンカー、対象外の文書は幕布のリンク |
| 画像 | リモート URL を保持、ローカルへダウンロード、または明示的に除外 |

結合セル、入れ子の表、不完全と判明したデータは、内容が欠けたまま成功扱いにならないよう明示的にエラーにします。アウトラインは幕布の操作画面を再現するものではありません。

## 自分の幕布文書をバックアップする

`fetch` は幕布のウェブ版の API を使用します。非公式ツールであり、API は変更されることがあります。アクセス権のある文書に限って使用してください。

1. ブラウザーで幕布にログインし、開発者ツールの Network パネルを開きます。
2. `api2.mubu.com` 宛ての文書リクエストを選び、リクエストヘッダーの `Jwt-Token` を探します。
3. 入力を非表示にするコマンドを実行し、値を貼り付けます。トークンはそのプロセス内だけで使用し、ファイルに保存しません。

```powershell
mubu-export fetch --cache cache/backup-001 --prompt-token
mubu-export inspect --cache cache/backup-001
mubu-export export --cache cache/backup-001 --out exports/backup-001 --images local
```

API が `data-unique-id` を要求する場合は環境変数 `MUBU_UNIQUE_ID` で指定します。自動化では `MUBU_TOKEN` からトークンを読み込めます。スクリプト、コマンドライン引数、スクリーンショット、Git にトークンを残さないでください。

バックアップでは文書一覧をページ単位で取得し、日次ノートを統合してから全件を再取得します。古いファイルが存在するだけで更新を省略することはありません。日次ノート API が失敗するとバックアップは中止されます。日次ノートが不要な場合は、`--no-daily` を明示してください。

ダウンロードと変換は同じドライブ上の一時ディレクトリで行い、全工程が成功した場合にのみ新しいディレクトリを出力します。既存のディレクトリは上書きしません。変換対象は `tree.json` に載っている文書に限られ、古いキャッシュに余分なファイルがあっても混入しません。

## よく使うオプション

```powershell
# ネットワークに接続せずローカルのキャッシュを変換
mubu-export export --cache cache/backup-001 --out exports/text --images skip --no-color

# 完全な入れ子リストを使用
mubu-export export --cache cache/backup-001 --out exports/bullets --style bullets

# フロントマターに元の文書 ID と幕布の URL を追加
mubu-export export --cache cache/backup-001 --out exports/with-source --source-metadata
```

既定の概要には件数だけが表示され、アカウント情報、文書名、文書 ID は表示されません。元の文書 ID と URL は既定ではフロントマターに入りません。本文、ファイル名、ノードのアンカー、元のリンク、画像には利用者の情報が含まれる場合があります。非公開のエクスポートを公開リポジトリにコミットしないでください。

画像リクエストには幕布のトークンを付けません。既定では公開 HTTPS アドレスだけから取得し、リダイレクト、プライベートネットワークのアドレス、画像以外の応答、空の応答、32 MiB を超えるファイルを拒否します。信頼できるローカルの画像取得元に限り、`--allow-private-images` で HTTP やプライベートネットワークのアドレスを許可できます。ダウンロード時は、外部サイトも含め、画像 URL が指すサーバーに接続します。

リンクのスキームと色の値は既定で検証され、安全でない値はエラーになります。`--trusted-input` は信頼できる入力に対してこの2つの検証を緩和します。出所が不明なキャッシュには使用しないでください。`--no-color` は本文を保持し、色の描画だけを省略します。

## ローカルキャッシュの形式

```text
cache/backup-001/
  tree.json          # folders と documents の一覧。文書 ID がキー
  docs/<id>.json     # {"meta": {...}, "data": {"definition": ..., "directory": [...]}}
  manifest.json      # 新しいバックアップのスキーマバージョンと文書数
```

`definition` は JSON オブジェクトまたは JSON を格納した文字列で、`nodes` リストが必須です。空のノートは `{"nodes": []}` と表します。ID に使用できるのは英字、数字、アンダースコア、ハイフンです。ノードは最大64階層、フォルダーは最大32階層です。同じ形式の既存キャッシュに対応します。非公開のキャッシュはソースリポジトリの外に保管してください。

出力は `index.md`、各ノート、`manifest.json` です。照合や移行に使えるように、マニフェストには文書数、画像モード、実際のファイルパスと SHA-256 を記録します。

## 開発と検証

```powershell
python -m pip install ".[dev]"
python -m pytest
python -m ruff check .
python -m build
```

テストには合成データのみを使い、ローカル HTTP サーバーへの実際のリクエストも検証します。幕布のアカウントは不要です。CI は Windows / Linux と Python 3.10 / 3.12 でテスト、lint、パッケージのビルド、インストール後のサンプル変換を実行します。公開 CI は幕布のオンライン API を使用しないため、オフラインテストだけでは API の互換性を確認できません。

## プライバシーと制限

ログインデータ、アカウント情報、実際のノート、非公開の診断記録、個人のスクリーンショットは収録していません。サンプルとテストは手作りの合成データです。トークンとバックアップへのアクセスを管理し、[プライバシーに関する説明](PRIVACY.md)を確認してください。

このツールは公式 API の安定性を保証せず、アクセス制御の回避や、ノートの AI・分析サービスへの送信も行いません。数式、ハイライト、穴埋め、HTML の対応は Markdown リーダーに依存します。添付ファイル、埋め込みページなど、対応表にない項目は変換できない場合があります。重要な資料を公開する前に、エクスポートを元の文書と照合してください。
